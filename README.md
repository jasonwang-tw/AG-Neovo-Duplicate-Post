# AG Neovo Duplicate Post

版本：**1.1.0** · [原始碼](https://github.com/jasonwang-tw/AG-Neovo-Duplicate-Post)

僅將文章與頁面複製為草稿，取代本站 Yoast Duplicate Post 的基本複製功能。

## 範圍與操作

- 文章／頁面清單提供 Clone（複製後回清單）、New Draft（複製後開啟草稿）。兩者都只建立草稿。
- 傳統編輯器發佈區與管理工具列提供 Copy to a new draft；區塊編輯器可使用工具列或清單入口，沒有新增區塊編輯器面板。
- 清單批次操作每次最多20筆，先驗證整份清單及 bulk-posts nonce；不符合範圍或權限時不建立任何草稿。若中途發生資料錯誤，已完成者保留，明確顯示成功／失敗數量。
- 保留標題、內文、摘要、ACF值及欄位參照、特色圖片ID、頁面模板、文章格式、分類／標籤、父頁面及選單順序。
- 副本固定 draft、作者為操作者、使用新日期及未指定slug。不複製密碼、留言、子頁面或媒體實體檔；媒體ID仍引用原檔。
- Polylang存在時使用API保留來源語系，不複製post_translations翻譯群組。沒有Polylang時安全降級為一般WordPress複製。
- 不複製編輯鎖、舊slug、垃圾桶、oEmbed快取及Yoast重寫關聯等狀態，另記錄 `_agneovo_duplicate_source` 作為副本來源。
- 不提供重寫與重新發佈、排程重新發佈、商品／訂單／優惠券／ACF欄位群組複製。商品與ACF群組使用各自原生功能。


## 後台管理頁（1.1.0）

入口：**工具 → Duplicate Post**，外掛清單亦提供「設定」。具 `edit_posts` 者可查看；這不會授予複製權限。

- 顯示複製功能接管、Yoast 啟用而待命，或掛鉤尚未完整註冊的實際狀態。
- 顯示文章／頁面支援範圍、複製／新增草稿差異及與實作共用的批次上限。
- 說明保留的 ACF、分類、圖片、模板與語系，以及不沿用網址、媒體檔案共用、草稿作者／日期和排除資料。
- 顯示目前帳號的 `copy_posts`、建立文章與建立頁面能力；每篇來源仍需通過原本的讀取／編輯及內容狀態檢查。
- 提供原生區段導覽、文章／頁面清單入口及回復 Yoast 的說明。沒有設定儲存、複製測試按鈕、角色變更或資料寫入。

沿用 WordPress 後台樣式；停用 JavaScript 仍可閱讀與導覽。介面英文來源及繁中 po／mo 均已更新。管理頁不讀取或顯示會員資料、來源文章內文或帳號個資。

## 架構及權限

- 複製流程由 `AGNeovo\DuplicatePost\Plugin` 負責，唯讀管理頁由 `Admin` 負責；無 JavaScript、CSS、npm build、外部服務或背景排程。
- 保留現有 copy_posts 權限，同時檢查讀取／編輯來源及建立該類型文章權限。不新增或修改角色能力。
- 每個單筆請求檢查來源ID對應nonce；批次請求檢查bulk-posts nonce。禁止垃圾桶、自動草稿及待重新發佈副本。
- 使用標準WordPress API，逐key讀取metadata的反序列化值，再保留字串反斜線後寫入；失敗時只移除該次未完成的新草稿。
- 繁體中文翻譯位於languages，其他語系使用英文訊息。新增介面文字時同步更新翻譯。

## 共存、切換及復原

Yoast `duplicate-post/duplicate-post.php`（含network啟用）存在時，不註冊新外掛複製 UI／操作 Hook；唯讀管理頁保留供查看狀態。驗證完成後啟用本外掛並停用Yoast；舊程式及設定均保留。

復原時先啟用Yoast，再停用本外掛。不還原整份 active_plugins 選項，以免覆蓋其他外掛後續啟停。草稿為一般WordPress資料，不需轉換；不刪除既有文章或歷史Yoast標記。

本站早期15筆失效的重新發佈關聯已唯讀核實，保留原值；本次未做資料清理。

## 驗證

執行 `php -l agneovo-duplicate-post.php`。正式站測試只建立可追蹤的草稿，核對post/page、ACF／多值／序列化資料與反斜線、分類、模板、特色圖片、語系及原翻譯關聯不變；檢查匿名／缺權限／不允許類型／錯誤nonce及批次流程。不要以建立管理員cookie代替UI驗收。
